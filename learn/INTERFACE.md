# 학습게임 공통 인터페이스 계약 (v2)

기존 `games/INTERFACE.md`(v1)를 그대로 상속하고, **학습게임용 규칙만 추가**한다.
오케스트레이터가 이 계약으로 검증한다.

## 0. 대상
- **초등학교 4~6학년(고학년)**. 어휘·문장·난이도 전부 이 기준.
- 교실 TV/빔프로젝터 + 교사 노트북. 소리 없음. 인터넷 없이 동작.

## 1. 모듈 형태 (v1과 동일)
- 파일: `learn/<이름>.js`, ES Module
- **default export = 게임 클래스 1개**
- 외부 라이브러리·CDN·웹폰트·원격 이미지·오디오 **금지**. 순수 Canvas 2D + 인라인 코드만.

## 2. 필수 메서드 (v1과 동일)
```js
export default class Game {
  constructor(canvas) { }  // 캔버스 보관, ctx 획득, 상태 초기화. 여기서 루프/리스너 시작 금지.
  start()  { }             // 루프 시작 + 키보드 리스너 등록. 중복 호출 안전.
  stop()   { }             // 루프 중지 + 리스너 전부 해제 + 타이머 정리. 중복 호출 안전.
}
```
- `stop()` 후 `start()` 재호출 시 **새 판이 정상 시작**되어야 한다.
- 리스너는 **바인딩된 참조를 필드에 저장**해서 `stop()`에서 정확히 제거(익명 함수 등록 금지).
- 루프는 `requestAnimationFrame`, id를 필드에 저장하고 `stop()`에서 `cancelAnimationFrame`.
- `setTimeout`/`setInterval`을 쓰면 id를 저장해 `stop()`에서 전부 정리.

## 3. 캔버스 규약 (v1과 동일)
- 논리 해상도 **800 x 600 고정**. `constructor`에서 `canvas.width=800; canvas.height=600`.
- 반응형은 셸 CSS 담당. 게임은 좌표 스케일링 신경 쓰지 않는다.
- 매 프레임 배경을 직접 칠한다. 배경 기본색 `#0b0b12`.

## 4. 셸 연동 훅 (옵셔널 호출)
```js
this.onScore    // (score:number) => void          점수 변할 때
this.onGameOver // (score:number) => void          게임 종료 시
this.onStats    // ({correct, wrong}) => void      정답/오답 개수가 변할 때  ★v2 추가
// 호출 형태: this.onScore?.(this.score)  /  this.onStats?.({correct:this.correct, wrong:this.wrong})
```
- 훅이 없어도 게임은 정상 동작해야 한다(반드시 옵셔널 체이닝).

## 5. 교사용 정보 named export ★v2 추가
셸의 "교사용 보기"에서 문제 범위를 펼쳐 보여준다. **문자열/배열만** 담는다(함수·클래스 금지).
```js
export const INFO = {
  subject: '수학',                 // 과목
  grade:   '5~6학년',              // 학년
  goal:    '한 문장 학습목표',
  minutes: 5,                      // 예상 활동 시간(분)
  howto:   '학생용 조작 안내 한 문장',
  items:   ['1/2 + 1/4 = 3/4', '...']  // 출제 범위/문항 목록 (정답 포함, 8~20개면 충분)
};
```

## 6. 조작 (학생 공통)
- 이동: **방향키** (WASD 병행 허용)
- 액션/발사: **스페이스바**
- 일시정지: **P** / 재시작: **R**
- **ESC는 셸 전용** — 게임은 절대 사용 금지.
- `preventDefault()`로 방향키·스페이스 스크롤 차단.

## 7. 학습게임 품질 기준 ★v2 추가 (중요)
- **문제는 캔버스 위쪽에 항상 크게 표시**(28px 이상, 굵게). 뒷자리에서 읽혀야 한다.
- 선택지/보기 텍스트는 **22px 이상**.
- **오답 처리는 부드럽게**: 즉시 게임오버 금지. 감점·속도 회복 정도로 하고,
  **정답이 무엇이었는지 화면에 1~2초 표시**해 준다(오개념 방지).
- 정답 시 짧은 시각 피드백(색·테두리 깜빡임 등). 애니메이션은 절제.
- 색만으로 정답/오답을 구분하지 않는다 — **O/X 기호나 텍스트를 함께** 표시.
- 한 문제는 **랜덤 생성 또는 목록에서 무작위 추출**. 같은 문제가 연속으로 나오지 않게.
- 오개념 금지: 수학은 계산 결과가 반드시 정확해야 하고, 분수는 기약분수 표기 원칙.
- 난이도: **시작 30초는 누구나 성공**. 이후 점진 상승.
- 안내 문구는 초등 고학년이 혼자 읽고 따라올 수 있는 한국어. 한 문장에 한 지시.

## 9. 실행 방식 주의
ES Module은 `file://` 더블클릭으로 열면 CORS 때문에 로드되지 않는다.
→ 오케스트레이터가 최종 통합 시 **단일 HTML 인라인 배포본**을 만든다.
따라서 워커는 코드에 `import`/동적 로딩을 넣지 말고, 파일 하나로 자급자족해야 한다.
